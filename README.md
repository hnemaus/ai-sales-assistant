# AI Sales Assistant

A lightweight AI toolkit designed to help sales teams reduce administrative work and focus more on customers.

Built by **Hanne Emaus** as part of exploring how AI can improve real commercial workflows.

---

## 💡 Problem

Sales teams spend too much time on:
- Writing CRM notes
- Following up after meetings
- Researching leads
- Handling repetitive objections

---

## ⚡ Solution

This repo provides ready-to-use AI prompts that turn manual sales tasks into fast workflows.

No coding required — just copy, paste, and use.

---

## 📦 What's inside

### Prompts
- Meeting summaries → structured CRM notes
- Follow-up emails → personalised outreach
- Lead research → quick company insights
- Objection handling → better sales responses

### Workflows
- Meeting → CRM automation step-by-step guide

---

## 🚀 Example workflow

**Before:** 25 minutes writing CRM notes  
**After:** 2–3 minutes using AI prompt

1. Paste meeting notes
2. Run prompt
3. Copy structured output to CRM
